# 🌿 Nature Gallery

Nature Gallery is a responsive image gallery built using React and Tailwind CSS. It showcases beautiful natural landscapes such as mountains, beaches, forests, waterfalls, lakes, deserts, and more through elegant cards with smooth hover effects.

## 📸 About the Project

This project was created to practice React fundamentals and responsive UI design. It displays a collection of nature images in a clean, modern layout while providing a smooth user experience across desktop, tablet, and mobile devices.

## ✨ Features

- Responsive image gallery
- Beautiful card-based layout
- Smooth hover animations
- Modern UI with Tailwind CSS
- Reusable React components
- Mobile, tablet, and desktop friendly

## ⚙️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/Nature-Gallery.git
```

2. Navigate to the project

```bash
cd Nature-Gallery
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```
